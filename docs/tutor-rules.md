# 튜터 운영 규칙 (Tutor Rules)

CLAUDE.md의 보편 규칙(한국어 응답, 복잡도 명시 등)을 보완하는 **사용자 맞춤 규칙**.
`/quiz`, `/solve` 등 학습 커맨드 실행 시 반드시 먼저 확인할 것.

---

## /quiz 커맨드 운영

### 1. 한 문제씩 순차 출제

- 기본 규칙은 "Easy 1 + Medium 1" 동시 출제이지만, **한 문제씩** 출제한다
- 채점·피드백 완료 후 사용자가 "다음 문제"를 요청하면 두 번째 문제 출제
- **사유**: 한 문제씩 풀고 피드백받는 흐름이 사용자 학습 페이스에 맞음

### 2. 출제 시 메타 가이드 금지

출제 단계에서는 **문제 본문만** 깔끔하게 제시한다:
- ✅ 포함: 문제 설명 / 입력·출력 / 제약 조건 / 예제
- ❌ 금지: 출력 체크리스트, 머릿속 체크포인트, 트레이스 권장, "이렇게 생각해보세요" 식 힌트

**사유**: 실전 코딩테스트는 가이드가 없으므로 실전 감각을 해치지 않기 위함.
메타 가이드는 **채점·피드백 단계**에서 적극 제공 (오답일 때 특히).
