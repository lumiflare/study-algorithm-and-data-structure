# 학습 기록 포맷 규약

`progress/` 디렉토리의 각 파일에 기록할 때 이 포맷을 따른다.

---

## wrong-answers.md (오답 노트)

```markdown
## [날짜] [카테고리]
- **문제**: (문제 요약)
- **오답**: (사용자의 접근법/코드 요약)
- **정답**: (올바른 접근법)
- **실패 원인**: (왜 틀렸는지 분석)
- **핵심 교훈**: (다음에 기억할 점)
```

극복 시 말미에 추기:
```
✅ 극복 [날짜]
```

---

## solve-log.md (풀이 기록)

```markdown
## [날짜] [카테고리] [문제명]
- **난이도**: Easy / Medium / Hard
- **소요 시간**: X분
- **자력 풀이 여부**: ✅ / 🔺(힌트 참고) / ❌(풀이 참고)
- **핵심 패턴**: [사용된 알고리즘 패턴]
- **시간 복잡도**: O(?)
- **공간 복잡도**: O(?)
```

---

## weekly-stats.md (주간 통계)

```markdown
## Week N ([시작일] ~ [종료일])
- **풀이 수**: X문제
- **자력 풀이율**: X%
- **난이도별**: Easy X / Medium X / Hard X
- **평균 소요 시간**: X분/문제
- **주요 학습 카테고리**: [카테고리 목록]
- **약점 카테고리**: [오답 다발 카테고리]
```

---

## dayN.md (일일 학습 기록)

```markdown
# Day N - [날짜]

## 학습 토픽
- [토픽1]: [이해도 ◎/○/△]
- [토픽2]: [이해도 ◎/○/△]

## 문제 풀이 성적
- 풀이 수: X문제
- 자력 풀이: X / 힌트 참고: X / 풀이 참고: X
- 주요 패턴: [사용한 알고리즘 패턴]

## 메모
- [중요한 깨달음이나 기억할 점]
```

---

## topics.md 운용 규칙

- `/explain <토픽>` 실행 → 해당 행 `[ ]` → `[~]`
- `/quiz`에서 자력 정답 → `[~]` → `[x]`
- `/quiz`에서 오답 → `[~]` → `[!]` + `wrong-answers.md` 기록
- `/review`에서 극복 → `[!]` → `[x]` + 오답 기록에 극복 마킹
