## 한국 기업

### 삼성 SW 역량테스트
- **형식**: 2문제 / 3시간 / C, C++, Java (Python 불가인 경우 있음 - 확인 필요)
- **플랫폼**: 삼성 자체 SW Expert Academy
- **난이도**: 백준 골드 3~플래티넘 수준

#### 빈출 유형 TOP 5
1. **시뮬레이션** — 2D 격자에서 복잡한 규칙 구현 (방향 전환, 격자 회전, 상태 변화)
2. **BFS/DFS** — 미로 탐색, 벽 부수기, 최단 경로 (상태 공간 BFS)
3. **구현** — 복잡한 조건 분기, 다중 루프 (정확한 구현력 중시)
4. **DP** — Tree DP, 구간 DP 등 고급 유형 증가 추세
5. **자료구조 복합** — Segment Tree, Priority Queue 활용

#### 핵심 전략
- **구현 정확성** > 알고리즘 다양성. 2문제를 정확히 푸는 것이 핵심
- 방향 벡터 (dx, dy), 격자 회전, 비트마스킹 코드를 미리 템플릿화
- 삼성 기출 백준 문제집: https://www.acmicpc.net/workbook/view/1152

### 카카오 코딩테스트
- **형식**: 5~7문제 / 5시간 / 다양한 언어 (Python 가능)
- **플랫폼**: 프로그래머스
- **난이도**: 앞 2문제 Easy, 중간 Medium, 마지막 1~2문제 Hard

#### 빈출 유형 TOP 5
1. **문자열 처리** — 파싱, 변환, 압축, 정규식
2. **해시/맵** — 빈도수, 캐싱, LRU
3. **그래프** — 경로 탐색, 최단 거리
4. **이진 탐색** — 파라메트릭 서치, 효율성 테스트
5. **그리디** — 스케줄링, 최적 선택

#### 핵심 전략
- 앞 3~4문제를 빠르게 풀고 뒤 문제에 시간 투자
- **효율성 테스트** 별도 존재 → 시간 복잡도 최적화 필수
- Python 문자열/딕셔너리 활용 극대화

### 네이버/라인
- **형식**: 3~4문제 / 2~3시간 / 다양한 언어
- **플랫폼**: 자체 또는 프로그래머스
- **난이도**: Medium 중심

#### 빈출 유형 TOP 5
1. **구현** — 조건에 맞는 정확한 구현
2. **자료구조** — 스택, 큐, 해시 활용
3. **그래프** — BFS/DFS, 연결 요소
4. **DP** — 기본~중급 DP
5. **정렬/탐색** — 정렬 후 이진 탐색

## 일본 기업

### メルカリ (Mercari)
- **형식**: 3~4문제 / 2시간
- **플랫폼**: LeetCode / 자체 코딩테스트
- **난이도**: AtCoder S랭크급, LeetCode Medium~Hard

#### 빈출 유형
1. **고급 DP** — 복잡한 상태 전이
2. **그래프 알고리즘** — 최단 경로, MST
3. **수학** — 조합론, 정수론
4. **자료구조** — 세그먼트 트리, 고급 구조

#### 핵심 전략
- LeetCode Hard 문제를 중점적으로 연습
- 수학적 사고력 강화 필수
- 코딩 면접(라이브 코딩)도 병행 준비

- HackerRank에서 Easy~Medium 문제 연습
