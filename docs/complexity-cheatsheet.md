# 시간/공간 복잡도 치트시트

## 자료구조 복잡도

| 자료구조 | 접근 | 탐색 | 삽입 | 삭제 | 공간 |
|---------|------|------|------|------|------|
| 배열 (Array) | O(1) | O(N) | O(N) | O(N) | O(N) |
| 연결 리스트 | O(N) | O(N) | O(1) | O(1) | O(N) |
| 스택 (Stack) | O(N) | O(N) | O(1) | O(1) | O(N) |
| 큐 (Queue) | O(N) | O(N) | O(1) | O(1) | O(N) |
| 해시맵 (HashMap) | - | O(1)* | O(1)* | O(1)* | O(N) |
| 이진 탐색 트리 | O(log N)* | O(log N)* | O(log N)* | O(log N)* | O(N) |
| 힙 (Heap) | O(1)** | O(N) | O(log N) | O(log N) | O(N) |
| 트라이 (Trie) | - | O(M) | O(M) | O(M) | O(ALPHABET × M × N) |

\* 평균 기준, 최악 O(N)
\** 최소/최대만 O(1)
M = 문자열 길이

## 정렬 알고리즘 복잡도

| 알고리즘 | 최선 | 평균 | 최악 | 공간 | 안정 |
|---------|------|------|------|------|------|
| 버블 정렬 | O(N) | O(N²) | O(N²) | O(1) | ✅ |
| 선택 정렬 | O(N²) | O(N²) | O(N²) | O(1) | ❌ |
| 삽입 정렬 | O(N) | O(N²) | O(N²) | O(1) | ✅ |
| 병합 정렬 | O(N log N) | O(N log N) | O(N log N) | O(N) | ✅ |
| 퀵 정렬 | O(N log N) | O(N log N) | O(N²) | O(log N) | ❌ |
| 힙 정렬 | O(N log N) | O(N log N) | O(N log N) | O(1) | ❌ |
| 팀 정렬 (Python) | O(N) | O(N log N) | O(N log N) | O(N) | ✅ |
| 계수 정렬 | O(N+K) | O(N+K) | O(N+K) | O(K) | ✅ |

## 그래프 알고리즘 복잡도

| 알고리즘 | 시간 복잡도 | 공간 | 용도 |
|---------|-----------|------|------|
| BFS | O(V+E) | O(V) | 최단 경로 (무가중) |
| DFS | O(V+E) | O(V) | 연결 요소, 사이클 |
| 다익스트라 (힙) | O((V+E) log V) | O(V) | 최단 경로 (양수 가중) |
| 벨만-포드 | O(V×E) | O(V) | 최단 경로 (음수 가중) |
| 플로이드-워셜 | O(V³) | O(V²) | 모든 쌍 최단 경로 |
| 크루스칼 | O(E log E) | O(V) | 최소 신장 트리 |
| 프림 (힙) | O(E log V) | O(V) | 최소 신장 트리 |
| 위상 정렬 | O(V+E) | O(V) | DAG 순서 결정 |
| Union-Find | O(α(N)) ≈ O(1) | O(N) | 집합 합치기/찾기 |

V = 정점 수, E = 간선 수

## 제약 조건 → 복잡도 가이드

| N 범위 | 허용 복잡도 | 대표 알고리즘 |
|--------|-----------|-------------|
| N ≤ 10 | O(N!) | 완전탐색, 백트래킹 |
| N ≤ 20 | O(2^N) | 비트마스킹, 부분집합 |
| N ≤ 100 | O(N³) | 플로이드-워셜, 3중 루프 |
| N ≤ 500 | O(N³) | DP (3차원) |
| N ≤ 1,000 | O(N²) | DP, 이중 루프 |
| N ≤ 5,000 | O(N²) | DP (조금 여유) |
| N ≤ 100,000 | O(N log N) | 정렬, 이진 탐색, 세그 트리 |
| N ≤ 1,000,000 | O(N) or O(N log N) | 투 포인터, 해시 |
| N ≤ 10,000,000 | O(N) | 선형 스캔, 에라토스테네스 |
| N ≤ 10^9 | O(log N) or O(√N) | 이진 탐색, 수학 |
