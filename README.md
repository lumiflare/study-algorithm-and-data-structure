# 알고리즘 & 자료구조 코딩테스트 학습

왕초보에서 한국+일본 대기업 코딩테스트 합격까지, Claude Code AI 튜터와 함께하는 16주 학습 리포지토리.

## 대상 기업

**한국**: 삼성 SW 역량테스트 / 카카오 / 네이버  
**일본**: メルカリ / LINE(LY) / 楽天 / サイバーエージェント / DeNA

## 학습 구조

```
16주 로드맵 (study-plan.md)
├── Phase 1 (Week 1~2)   — Python 기초, 복잡도
├── Phase 2 (Week 3~6)   — 핵심 자료구조
├── Phase 3 (Week 7~10)  — 핵심 알고리즘
├── Phase 4 (Week 11~14) — 고급 주제
└── Phase 5 (Week 15~16) — 실전 대비
```

## 슬래시 커맨드 (AI 튜터)

| 커맨드 | 기능 | 사용 예 |
|--------|------|---------|
| `/explain` | 개념/알고리즘 설명 | `/explain 이진 탐색` |
| `/quiz` | 코딩 퀴즈 출제 | `/quiz 배열 & 해싱` |
| `/solve` | 문제 풀이 가이드 (힌트→접근→풀이) | `/solve 백준 1920` |
| `/review` | 일일 복습 세션 | `/review` |
| `/progress` | 학습 진도 확인 | `/progress` |
| `/weak-points` | 약점 분석 | `/weak-points` |
| `/mock-test` | 모의 코딩 테스트 | `/mock-test 삼성` |
| `/trace` | 코드 트레이싱/드라이런 | `/trace BFS` |
| `/pattern` | 알고리즘 패턴 인식 훈련 | `/pattern 종합` |
| `/company` | 기업별 코딩테스트 대비 | `/company 카카오` |

## 1일 학습 사이클 (2~3시간)

1. `/explain` — 새 토픽 학습 (30분)
2. `/solve` or `/quiz` — 문제 풀이 2~3개 (60~90분)
3. `/review` — 오답 복습, 핵심 정리 (15~30분)

## 디렉토리 구조

```
├── notes/       — 20개 카테고리별 개념 노트
├── solutions/   — 풀이 코드 (카테고리별 .py)
├── progress/    — 학습 진도, 오답 노트, 풀이 기록
├── docs/        — 레퍼런스 (토픽 트리, 기업 프로필, 복잡도 치트시트)
└── templates/   — 트레이스/풀이 템플릿
```

5. 이진 탐색 / 6. 연결 리스트 / 7. 트리 / 8. 트라이
9. 힙 / 10. 백트래킹 / 11. 그래프 / 12. 고급 그래프
13. 1D DP / 14. 2D DP / 15. 그리디 / 16. 구간
17. 수학 & 기하 / 18. 비트 조작
19. **시뮬레이션** (삼성 핵심) / 20. **문자열 처리** (카카오 핵심)
