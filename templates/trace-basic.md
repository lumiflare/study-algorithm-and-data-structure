# 기본 트레이스 템플릿

코드의 변수 변화를 단계별로 추적하는 표.

## 사용법
1. 변수 열을 코드에 등장하는 변수로 교체
2. 각 단계(루프 반복, 조건 분기)마다 한 행 추가
3. 변경된 값은 **굵게** 표시

## 템플릿

| 단계 | 변수1 | 변수2 | 변수3 | 조건/분기 | 비고 |
|------|-------|-------|-------|----------|------|
| 초기 |       |       |       |          | 초기값 설정 |
| 1    |       |       |       |          |      |
| 2    |       |       |       |          |      |
| ...  |       |       |       |          |      |
| 종료 |       |       |       |          | 반환값: |
