# 재귀 트레이스 템플릿

재귀 호출의 콜 트리와 반환값을 추적하는 표.

## 콜 트리 시각화

```
func(4)
├── func(3)
│   ├── func(2)
│   │   ├── func(1) → base case: 반환값
│   │   └── func(0) → base case: 반환값
│   └── 반환값
└── 반환값
```

## 호출 추적 표

| 호출 순서 | 함수 호출 | 인수 | 재귀 호출 | 반환값 | 비고 |
|----------|----------|------|----------|--------|------|
| 1 | func(4) | n=4 | func(3), func(2) | ? | |
| 2 | func(3) | n=3 | func(2), func(1) | ? | |
| ...| ... | ... | ... | ... | |

## 스택 프레임 추적

| 시점 | 콜 스택 (위가 현재) | 현재 실행 |
|------|-------------------|----------|
| t0 | func(4) | 진입 |
| t1 | func(3), func(4) | 재귀 호출 |
| ... | ... | ... |
