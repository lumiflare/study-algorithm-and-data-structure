오늘의 학습 내용을 정리하고, 복습 세션을 진행해주세요.

## 순서

### 1. 오늘의 학습 요약
- `study-plan.md`에서 오늘의 학습 예정 확인
- 오늘 세션에서 다룬 토픽 정리
- 풀이한 문제 수와 정답률 (`progress/solve-log.md`에서 오늘 날짜 기준)

### 2. 오답 복습
- `progress/wrong-answers.md`의 오늘분 (또는 직근) 읽기
- 같은 유형의 유사 문제를 1문제 재출제
- 맞히면 오답 기록 말미에 `✅ 극복 [날짜]` 추기

### 3. 핵심 패턴 확인
- 오늘 배운 핵심 패턴 3~5가지를 나열
- 각 패턴을 한 문장으로 설명하게 유도
- 「이 패턴은 어떤 상황에서 사용하나요?」식 질문

### 4. 코드 스니펫 퀴즈
- 오늘 학습한 알고리즘의 핵심 부분만 빈칸으로 만든 미니 퀴즈 1문제
- 예: BFS의 큐 처리 부분, DP의 점화식 부분

### 5. 내일 예고
- `study-plan.md`에서 내일의 학습 내용 안내
- 오늘과의 연관성 설명

### 6. 학습 기록 저장
- `progress/` 디렉토리에 `dayN.md`로 오늘의 학습 기록 저장

## 기록 포맷 (progress/dayN.md)

```markdown
# Day N - [날짜]

## 학습 토픽
- [토픽1]: [이해도 ◎/○/△]
- [토픽2]: [이해도 ◎/○/△]

## 문제 풀이 성적
- 풀이 수: X문제
- 자력 풀이: X / 힌트 참고: X / 풀이 참고: X
- 주요 패턴: [사용한 알고리즘 패턴]

## 메모
- [중요한 깨달음이나 기억할 점]
```
