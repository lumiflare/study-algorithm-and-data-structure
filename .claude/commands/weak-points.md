오답 기록을 분석하여 약점을 특정하고 대책을 제안해주세요.

## 순서

1. `progress/wrong-answers.md` 읽기
2. `progress/solve-log.md` 읽기 (시간 초과, 힌트/풀이 참고 비율 분석)
3. 카테고리별·패턴별 오답 분류 및 집계
4. 약점 패턴 분석

## 보고 형식

### 카테고리별 약점 TOP 5
1. [카테고리명]: X문제 오답 — [공통 실패 패턴]
2. ...

### 자주 발생하는 실수 유형
- **유형 1**: [예: 엣지 케이스 누락 — 빈 배열, 단일 원소]
- **유형 2**: [예: 인덱스 오류 — off-by-one]
- **유형 3**: [예: 시간 초과 — 불필요한 중첩 루프]
- **유형 4**: [예: 점화식 설정 오류]

### 패턴 인식 능력 분석
- 잘 인식하는 패턴: [...]
- 못 인식하는 패턴: [...]

### 집중 복습 대상
1. [토픽] — [왜 중요한지, 어떻게 극복할지]
2. ...

### 추천 행동
- 약점 카테고리 → `/explain [토픽]`으로 재학습
- 자주 틀리는 유형 → `/quiz [카테고리]`로 집중 연습
- 패턴 인식 강화 → `/pattern [유형]`으로 훈련
- 시간 관리 → `/mock-test`로 실전 감각 강화

## 복습 퀴즈

약점 분야에서 3문제 복습 퀴즈 출제:
- 문제 제목에 힌트 넣지 않기
- 자주 틀리는 유형에서 선별
- 관련 개념의 간결한 재설명 (핵심 한 문장 / 패턴 요약)
