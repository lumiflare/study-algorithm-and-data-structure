알고리즘 패턴 인식 능력을 훈련합니다.
문제를 보고 **어떤 알고리즘/자료구조를 써야 하는지 판단하는 능력**을 기릅니다.

## 입력
$ARGUMENTS

인수 예:
- 인수 없음 → 랜덤 유형으로 패턴 인식 퀴즈
- `투 포인터` → 투 포인터 패턴 집중 훈련
- `종합` → 여러 패턴이 섞인 종합 훈련

## 모드 1: 패턴 인식 퀴즈 (기본)

5개의 **짧은 문제 설명**을 제시하고, 각각에 적합한 알고리즘 패턴을 맞히게 한다.

```
문제 N:
[문제 설명 (3~4문장)]
제약 조건: [N의 범위, 시간 제한]

→ 이 문제에 가장 적합한 알고리즘 패턴은?
```

선택지:
ㄱ. 브루트포스 / ㄴ. 투 포인터 / ㄷ. 슬라이딩 윈도우 / ㄹ. 이진 탐색
ㅁ. BFS/DFS / ㅂ. DP / ㅅ. 그리디 / ㅇ. 백트래킹 / ㅈ. 해시맵 / ㅊ. 스택

## 모드 2: 패턴 심화 (특정 패턴 집중)

특정 패턴이 인수로 주어진 경우:
1. 해당 패턴의 **적용 조건** 3가지를 설명
2. 해당 패턴이 적합한 문제 3개 + 적합하지 않은 문제 2개를 제시
3. 사용자에게 적합/부적합을 판별하게 함
4. 해당 패턴의 **코드 템플릿** (Python) 제시

## 모드 3: 종합 훈련

1. 문제를 1개 제시
2. 사용자가 패턴을 선택
3. 선택한 패턴으로 의사코드 작성 유도
4. 실제 Python 코드 작성
5. 다음 문제로 (점차 난이도 상승)

## 패턴 인식 시그널 키워드 (채점 시 출력)

| 패턴 | 시그널 키워드 / 조건 |
|------|---------------------|
| 해시맵 | 「빈도수」「중복」「쌍 찾기」「O(1) 조회」 |
| 투 포인터 | 「정렬된 배열」「쌍의 합」「부분 배열」 |
| 슬라이딩 윈도우 | 「연속 부분 배열」「길이 K」「최대/최소 구간」 |
| 스택 | 「괄호 매칭」「단조 스택」「가장 가까운 큰 수」 |
| 이진 탐색 | 「정렬됨」「O(log N)」「최소값의 최대화」 |
| BFS | 「최단 거리」「레벨별 탐색」「미로」 |
| DFS | 「모든 경로」「연결 요소」「순열/조합」 |
| DP | 「최적 부분 구조」「중복 부분 문제」「경우의 수」 |
| 그리디 | 「매 순간 최선」「정렬 후 선택」「활동 선택」 |
| 백트래킹 | 「모든 조합」「제약 조건 만족」「N-Queens」 |
| Union-Find | 「연결 여부」「그룹 합치기」「사이클 감지」 |
