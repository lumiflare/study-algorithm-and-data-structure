학습 진도를 **카테고리별 토픽 단위**로 집계하여 보고해주세요.

## 순서

1. `progress/topics.md`를 Read하여 각 토픽의 상태 집계
   - `[ ]` 미학습 / `[~]` 학습중 / `[x]` 학습완료 / `[!]` 복습필요
2. `study-plan.md`와 대조하여 현재 몇 주차에 해당하는지 추정
3. `progress/wrong-answers.md`에서 카테고리별 오답 수 분석
4. `progress/solve-log.md`에서 풀이 통계 집계
5. `progress/weekly-stats.md`에서 주간 추이 확인

## 보고 형식

```
📅 오늘: [날짜] | 학습 시작일로부터: [N]일째
학습 플랜 기준: Week [X] / 16주 (Phase [Y])
━━━━━━━━━━━━━━━━━━━━━━━

### 전체 진도 (토픽 단위)
- 학습완료 [x]: XXX개 (XX.X%)
- 학습중   [~]: XXX개 (XX.X%)
- 복습필요 [!]: XXX개 (XX.X%)
- 미학습   [ ]: XXX개 (XX.X%)

### 카테고리별 진도
| # | 카테고리 | 진도 | 바 | 중요도 |
|---|---------|------|-----|--------|
| 1 | 배열 & 해싱 | x/y (XX%) | ████░░░░░░ | ★★★ |
| 2 | 투 포인터 | x/y (XX%) | ███░░░░░░░ | ★★ |
| ... | ... | ... | ... | ... |

### 문제 풀이 통계
- 총 풀이 수: X문제 / 250문제
- 자력 풀이율: X%
- 난이도별: Easy X / Medium X / Hard X
- 평균 소요 시간: X분/문제

### 주간 추이 (최근 4주)
| 주 | 풀이 수 | 정답률 | 평균 시간 |
|----|---------|--------|----------|

### 복습 필요 토픽 [!] (최대 10건)
- 카테고리 → 토픽명 (마지막 오답 날짜)

### 다음 우선 사항
1. 가장 진도가 느린 핵심 카테고리
2. 복습 필요 [!] 토픽 재학습
3. 다음 단계의 새 카테고리 진입

### 어드바이스
[학습 페이스, 분야 균형, 강화해야 할 점에 대한 조언]
```

## 진도 바 표시

10단계 시각화:
- 0%: ░░░░░░░░░░
- 50%: █████░░░░░
- 100%: ██████████

진도 계산은 `[x]`만 완료로 카운트 (`[~]`는 학습중, 미완료).
