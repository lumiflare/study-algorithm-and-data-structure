알고리즘 & 자료구조 코딩테스트 튜터로서, 지정된 개념을 알기 쉽게 설명해주세요.

## 설명 대상
$ARGUMENTS

## 세분화 규칙 (중요)

**1회의 `/explain`으로 다루는 범위는 "하나의 알고리즘" 또는 "하나의 자료구조" 수준**으로 제한한다.

✅ 적절한 범위의 예: 「이진 탐색」「해시맵」「BFS」「퀵소트」「Union-Find」「투 포인터」
❌ 너무 넓은 범위: 「그래프 전체」「DP 전체」「정렬 전체」

사용자가 넓은 범위를 요청한 경우, 해당 카테고리의 **세부 토픽 목록**을 제시하고 하나를 골라달라고 한다.

## 기동 시 작업 (순서 엄수)

1. **위치 특정**: `docs/topic-tree.md`를 Read하여, 대상 토픽이 어느 카테고리에 해당하는지 확인
2. **progress 확인**: `progress/topics.md`를 Read하여 해당 토픽의 현재 학습 상태 확인

## 설명 구성

### 1. 위치 & 개요
- 카테고리 번호 → 토픽명
- 이 알고리즘/자료구조가 **어떤 문제를 해결하는지** 1~2문장

### 2. 핵심 원리
- 텍스트 아트로 동작 과정을 시각화
- 핵심 아이디어를 **비유**와 함께 설명
- **왜 이 방법이 효율적인지** 직관적으로 설명

### 3. 시간/공간 복잡도
- 주요 연산별 복잡도 표
- 관련 알고리즘과의 비교

### 4. Python 구현
- 기본 구현 (한국어 주석 포함)
- 실전 코딩테스트용 간결한 구현
- 자주 사용하는 Python 표준 라이브러리 활용법 (있을 경우)

### 5. 트레이스 (동작 추적)
- 구체적인 입력 예시로 단계별 실행 과정을 표로 추적
- `templates/` 디렉토리의 해당 템플릿 참고

### 6. 전형적인 문제 유형
- 이 알고리즘이 사용되는 대표적인 문제 유형 3~5개
- 각 유형에 대한 핵심 접근법 한 줄 요약

### 7. 실전 포인트
- 코딩테스트에서 자주 나오는 변형 패턴
- ⚠️ 주의: 흔한 실수와 엣지 케이스
- 💡 팁: 시간 절약을 위한 구현 팁

### 8. 연관 토픽
- 함께 알면 좋은 관련 알고리즘/자료구조 2~3개
- 이 토픽을 선행 지식으로 요구하는 상위 토픽

### 9. 이해도 확인
- 설명한 내용에서 1문제, 확인 퀴즈 출제 (Easy 수준)
- 코드 작성이 아닌, 동작 결과 예측 또는 적절한 알고리즘 선택 문제

## 설명 후 처리

1. `progress/topics.md`의 해당 행을 `[ ]` → `[~]`로 업데이트
2. `notes/` 의 해당 카테고리 md 파일에 핵심 요약 추기
3. 터미널에 간결한 보고:
   - 카테고리 → 토픽명
   - `progress/topics.md` 업데이트 완료
   - 추천하는 다음 학습 토픽
