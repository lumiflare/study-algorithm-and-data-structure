알고리즘 & 자료구조 코딩테스트 퀴즈를 출제해주세요.

## 인수
$ARGUMENTS

## 규칙

- 인수가 지정된 경우 해당 카테고리에서 출제
- 인수가 없는 경우 `progress/topics.md`에서 `[~]` 또는 `[!]` 상태인 토픽 중 랜덤 선택
- 1회에 2문제 출제 (Easy 1 + Medium 1)
- Python으로 풀이

## 출제 포맷 (중요)

- **문제 제목에 힌트를 넣지 않는다**: 「문제 1」「문제 2」만 표시
- **정답 예시를 포함하지 않는다**

### 문제 N

[문제 설명]

**입력**: [입력 형식과 예시]
**출력**: [출력 형식과 예시]

**제약 조건**:
- [시간 제한, 입력 범위 등]

**예제**:
```
입력: [예제 입력]
출력: [예제 출력]
설명: [왜 이 답인지]
```

---
코드를 작성해주세요.

## 채점 후 처리

사용자가 코드를 제출하면:

1. **정확성 확인**: 예제 + 엣지 케이스로 검증
2. **복잡도 분석**: 시간/공간 복잡도 판정
3. **코드 리뷰**:
   - 더 나은 접근법이 있는지
   - 불필요한 연산이 있는지
4. **모범 답안 제시**: 최적 풀이 + 핵심 패턴 설명
5. **개념 교육** (간략 포맷):
   - 핵심 한 문장
   - 패턴 인식 포인트
   - 유사 문제에 적용하는 법
6. **오답 시**:
   - 실패 원인 분석 (로직 오류 / 엣지 케이스 / 복잡도 초과)
   - `docs/records.md`를 Read하여 포맷 확인 후 `progress/wrong-answers.md`에 추기
7. **풀이 기록**: `docs/records.md`를 Read하여 포맷 확인 후 `progress/solve-log.md`에 추기
8. `progress/topics.md` 업데이트 (자력 정답→`[x]`, 오답→`[!]`)
