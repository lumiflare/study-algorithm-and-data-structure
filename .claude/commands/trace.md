코드의 단계별 실행 과정을 추적(트레이스)해주세요.

## 입력
$ARGUMENTS

인수로 주어지는 것:
- Python 코드 (직접 붙여넣기)
- 알고리즘명 + 입력 데이터 (예: `BFS [1,2,3,4,5] 그래프`)
- `연습` → 현재 학습 카테고리에서 문제 자동 출제 후 트레이스 연습

## 출력 구성

### 1. 코드 개요
- 이 프로그램이 무엇을 하는지 1~2줄로 설명
- 핵심 알고리즘/자료구조 명시

### 2. 트레이스 표

| 단계 | 변수1 | 변수2 | 자료구조 상태 | 비고 |
|------|-------|-------|-------------|------|
| 초기 |       |       |             |      |
| 1    |       |       |             |      |
| ...  |       |       |             |      |
| 종료 |       |       |             | 반환값: |

### 3. 각 단계 해설
- 루프 경계 조건
- 조건 분기 판정 근거
- 자료구조 연산 (push/pop, enqueue/dequeue 등)
- 함수 호출과 반환값

### 4. 시각화 (해당하는 경우)
- BFS/DFS → 방문 순서를 그래프/트리 텍스트 아트로
- 정렬 → 각 단계의 배열 상태
- 스택/큐 → 내부 상태 변화
- 트리 → 노드 삽입/삭제 과정

### 5. 흔한 실수
- 인덱스 오류 (0-based vs 1-based)
- 루프 종료 조건 착각
- 재귀 반환값 추적 실패

## 레벨 선택 (선택)

인수 끝에 `level=1` `level=2` `level=3` 지정 가능.

- **level=1**: 모든 변수를 매 단계 표시 (초보·전체 파악) [기본값]
- **level=2**: 변화된 변수만 표시 (중급·효율화)
- **level=3**: 핵심 포인트만 언어화 (상급·실전 감각)

## 연습 모드

인수가 「연습」인 경우:
1. `progress/solve-log.md`에서 최근 학습 카테고리 확인
2. 해당 카테고리에서 짧은 코드(10~20줄) 출제
3. 사용자에게 결과를 예측하게 한 뒤, 정답 트레이스 표 제시
4. 맞으면 다음 레벨, 틀리면 같은 레벨 재도전
